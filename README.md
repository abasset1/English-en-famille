# English en famille

Petite web app pour pratiquer l'anglais en famille, 10 minutes par jour.

- **Aujourd'hui** : le rituel du jour, les phrases à dire (avec audio) et la checklist quotidienne
- **Mots** : imagier de 8 thèmes (couleurs, animaux, nourriture, corps, famille, vêtements, météo, maison)
- **Jeux** : Memory, What's missing?, Listen & find, et les règles des jeux à faire en vrai
- **Étoiles** : tableau d'étoiles de la semaine, objectif et récompense

Un seul fichier `index.html`, sans dépendance. Les étoiles sont enregistrées dans le navigateur de l'appareil (localStorage). La prononciation utilise la synthèse vocale du navigateur.

## Mise en ligne

Settings › Pages › Deploy from a branch › `main` / `(root)`.
Sur le téléphone : ouvrir le lien puis « Ajouter à l'écran d'accueil ».
